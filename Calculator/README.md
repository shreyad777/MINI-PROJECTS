# 🧮 Professional Calculator

A Python calculator application that provides both a command-line interface and a graphical user interface using Tkinter.

## ✨ Features

### Command-Line Calculator

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Floor division
- Square root
- Percentage
- Absolute value
- Calculation history
- Input validation
- Error handling

### GUI Calculator

- 🖥️ Tkinter graphical interface
- ➕ Basic arithmetic
- √ Square root
- % Percentage
- ^ Power
- ⌫ Backspace
- 🧹 Clear
- ⌨️ Keyboard support
- 📜 Calculation history
- ⚠️ Error messages

## 🛠️ Technologies

- Python
- Tkinter
- Math module
- Git
- GitHub

### Command-Line Version

```bash
python calculator.py

python calculator_gui.py
