# 🧮 Advanced Calculator

A Python-based calculator that performs basic and advanced mathematical operations through a command-line interface.

## ✨ Features

### Basic Operations

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division

### Advanced Operations

- `%` Modulus
- `^` Power
- `//` Floor Division
- `√` Square Root
- `%` Percentage
- Absolute Value

### Additional Features

- 📜 Calculation history
- ⚠️ Invalid input handling
- 🛡️ Division-by-zero protection
- 🔄 Continuous calculations
- 🚫 Negative square-root validation

## 🛠️ Technologies

- Python
- `math` module
- Functions
- Loops
- Conditional statements
- Exception handling
