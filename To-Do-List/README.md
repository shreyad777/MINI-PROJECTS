# 📝 To-Do List

A simple Python-based To-Do List application that allows users to create, view, complete, and delete tasks.

This project is designed to practice fundamental Python programming concepts such as lists, dictionaries, functions, loops, conditional statements, exception handling, and user input.

## 🎯 Objectives

- Create and manage tasks.
- Display all available tasks.
- Mark tasks as completed.
- Delete tasks.
- Practice Python functions.
- Practice data structures.
- Build a simple command-line application.

## ✨ Features

- ➕ Add new tasks
- 📋 View all tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- ⚠️ Input validation
- 💻 Simple command-line interface

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Main programming language |
| Lists | Store tasks |
| Dictionaries | Store task information |
| Functions | Organize program logic |
